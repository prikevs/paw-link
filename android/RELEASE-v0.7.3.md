# PawLink Capture 0.7.3 · 直接操作与标注状态

- 移除标注页的「更多」入口。顶部直接查看片段列表和已标注记录；直接播放选段、前后预览和全片，并新增手动片段。
- 底部横向操作条提供调整时间、排除、撤销、拆分、合并、同步、保存、导出、书签和事件预览。同步与导出各自保留有名称的专用选择对话框。
- 当前片段显示待标注、已标注、已排除、已跳过、待重新确认或修改尚未保存。已保存区间显示行为及时间范围，编辑时按钮改为「保存修改」。
- 时间轴显示黄为候选、绿为已标、红为排除；片段列表区分已标注、待标注和已跳过。
- 调整范围时实时显示重叠的已有区间。保存冲突时列出所有冲突标注的行为、原始范围及具体交叉区间，点击进入原标注修改；原有数据不会自动覆盖。
- 播放定位与循环沿用 v0.7.2。无需更新固件。

验证：构建与 Android 静态检查通过；Pixel 真机验证实时重叠警告、冲突行为及交叉区间、已有标注状态和保存修改按钮、直接操作布局；选段播放循环和完整播放、保存前进、跳过撤销及恢复进度回归检查通过。使用独立合成测试记录，已采集资料保留。
