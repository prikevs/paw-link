# PawLink Capture 0.7.2 · 播放范围

- 主界面的「播放选段」播放当前人工选定的起止区间，并在区间内循环。
- 「更多 → 播放范围」提供选定区间、含前后余量和完整视频三个入口。
- 含前后余量使用当前已扩展的预览范围并循环；完整视频从 0 秒播放，到结尾停止。
- 播放中主按钮为「暂停」；暂停后点击「播放选段」重新从选区起点播放。
- 切换播放范围不会改动人工标注边界。进入候选时仍自动预览前后背景。
- 修正先开始播放后异步定位的竞态：播放器准备完成后精确定位，收到定位完成通知才开始播放，循环同样等待定位完成。

验证：APK、测试 APK 和 Android 静态检查通过。Pixel 真机合成录像验证 6–7 秒选区实际从 6 秒开始、跨循环仍停留在该区间、完整播放从 0 秒开始且结尾停止、标注边界保持；原有保存前进、跳过撤销、恢复进度和布局检查通过。已有采集资料保留；无需更新固件。
