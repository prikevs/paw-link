# PawLink Capture 0.6.0

2026-09-26 · Android 原生采集版

- 采集 / 记录 / 设备三个页面，浅色绿色界面。
- 实时 IMU、设备预测、电压、估算电量、充电状态；GATT 串行订阅和断连重试。
- 采集必须有近期 IMU 数据；录像结束后落盘再打开复核。
- 原始视频、IMU、视觉候选与 evidence.csv 独立保存；书签、连接事件及多猫身份不确定记录。
- 七类 + unknown 人工复核，波形定位、分段/合并、边界调整、一步撤销、同步偏移校正。
- 复核草稿原子替换；显式保存创建不可变 reviews/revision-*，旧原始文件与旧版复核文件不覆盖。
- 原始资料和训练资料 ZIP 通过 Android 文件选择器导出；训练样本要求人工确认、可用行为、无检测到的序列缺口及手工核对同步。

## 当前边界

此版本是可安装采集版，尚未实现设计中的猫档案管理、按异常优先的复核队列、独立姿态子标签、逐帧解码以及编码 PTS 自动校准。视频同步以接收时钟为基线，提供人工偏移校正；勾选同步确认不代表测得了确定的毫秒精度。设备源标签不能自动成为人工真值。

多猫只会标记身份不确定，不提供稳定跨帧身份跟踪；供电百分比是电压估计，未充电不代表满电。当前仅竖屏。长会话保存/波形加载仍需专门压力测试。测试摄像头未出现猫时只能验证数据链路，不能验证真实七类行为识别。
